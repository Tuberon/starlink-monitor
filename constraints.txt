# з requirements.txt). Без цього на кожному встановленні бралися найновіші
# сумісні версії, а `update.sh` пропускає pip, коли requirements.txt не змінився,

#   pip install -r requirements.txt -c constraints.txt

# вважає зміну цього файлу "суттєвою" (нові імена в requirements.txt = повне
# перевстановлення), а лише перевстановлює версії, що відрізняються.
#

# коментар у scripts/install.sh).
#
# Оновлення (раз на квартал або після pip-audit):
#   python3 -m venv /tmp/v && grep -vi '^adafruit' requirements.txt | /tmp/v/bin/pip install -r /dev/stdin
